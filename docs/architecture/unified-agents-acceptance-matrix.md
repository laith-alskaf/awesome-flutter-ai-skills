# مصفوفة قبول انتقال `.agents/`

| المجال | الشرط القابل للتحقق | النجاح | الفشل الذي يمنعه |
|---|---|---|---|
| المهارات | توجد كل مهارة في `.agents/skills/<name>/SKILL.md` مباشرة. | عدّ المهارات يساوي catalog المعلن ولا يظهر مجلد مصدر متداخل. | اكتشاف غير موثوق أو المسار `.agents/skills/skills/...`. |
| القواعد | توجد قاعدة مشروع قصيرة في `.agents/rules/` وتستخدم مراجع إلى context وgovernance. | تستوفي القاعدة حد الحجم وتحتوي مسارات صحيحة. | تحميل حوكمة غير مرتبط أو تكرار نصوص طويلة. |
| الحوكمة | الملفات المشتركة توجد في `.agents/governance/`. | لا توجد مراجع تثبيت جديد تكتب إلى `.agent/core/`. | ازدواجية سياسة أو اختلاف بين المحررات. |
| السياق | ملفات profile/state/index/log توجد في `.agents/context/`. | حالة العمل تسجل الدليل والقرار والتحقق فقط عند الحاجة. | ذاكرة مضخمة أو فقدان التسليمات. |
| عدم الإتلاف | التشغيل دون `-Force` لا يغير ملفات الفريق أو context الموجود. | مقارنة hashes قبل وبعد ناجحة. | فقدان تخصيصات أو سجل المشروع. |
| الترحيل | `-MigrateLegacy -DryRun` يكتشف التعارضات، و`-MigrateLegacy` ينشئ backup. | لا تفقد ملفات `.agent/` وتتحول references إلى `.agents/`. | حذف صامت أو انتقال جزئي. |
| محولات المحررات | كل adapter يشير إلى المسارات الجديدة وبنفس ترتيب الأولوية. | فحص نصي في CI يمر. | تعليمات متعارضة بين Antigravity وCursor وCopilot وغيرها. |
| Windows CI | يهيئ fixture ثم يتحقق من بنية `.agents/` فقط. | تشغيل PowerShell ناجح على `windows-latest`. | رجوع خطأ تثبيت أو مسارات غير أصلية. |
| توافق Antigravity الحي | يظهر skill catalog وworkspace rule في المحرر. | سجل اختبار حي يوثق البيئة ونوع التفعيل والنتيجة. | افتراض توافق من فحص نصي فقط. |
